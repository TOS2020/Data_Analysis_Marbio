Data Analysis Marbio web application
A web-based tool designed for the analysis of bioactivity assay data. This application supports the data processing needs of Marbio research platform.
________________________________________
Features
•	Upload raw data in Excel format and enter the investigator’s name
•	Select the assay type and verify the corresponding microtiter plate layout
•	Enter the sample names
•	Choose a destination folder to save the analysis results as a separate Excel file
•	Access information about Marbio and its LinkedIn page
